## 2. What Changed Today (`1.0.0-rc.5` → `1.0.0-rc.6` → `d22a016`)

### Shipped in `1.0.0-rc.6` (`28c97f7`, `01cbd66`)
1. **Automatic context injection through hooks (`src/hook.ts`, `src/hooks/normalize.ts`, `src/clients/hooks.ts`):**
   - `baglam setup` now installs session-start hooks alongside prompt/edit/stop hooks:
     - **Claude Code:** `SessionStart` + `UserPromptSubmit` → `hookSpecificOutput.{hookEventName, additionalContext}`
     - **Codex CLI:** `SessionStart` + `UserPromptSubmit` → `hookSpecificOutput.{hookEventName, additionalContext}`
     - **Gemini CLI:** `SessionStart` + `BeforeAgent` → `hookSpecificOutput.{hookEventName, additionalContext}`
     - **Cursor:** `sessionStart` → `{ additional_context }` (`beforeSubmitPrompt` strictly stays `{"continue":true}`)
     - **VS Code Copilot:** `sessionStart` → `hookSpecificOutput.{additionalContext}`
   - Injects compact brief (`budgetTokens: 900`) on `start` only when a live task or approved records exist.
   - On `prompt`, injects compact handoff (`2400` chars max) only when control switches from a **different agent** and `start` has not already injected that exact handoff timestamp (preventing both turn-by-turn spam and `SessionStart` + first-prompt double injection).
   - Opt-out via `BAGLAM_HOOK_INJECT=0`.
2. **Linux clipboard hang fix (`src/clipboard.ts`, `src/host.ts`):**
   - `wl-copy` / `xclip` fork a background process keeping stdout/stderr pipes open. Clipboard commands now run with `stdio: ["pipe", "ignore", "ignore"]` and a 10 s timeout (`RunOptions.background = true`). Verified with a real POSIX background-child test on Ubuntu/macOS CI and a live Windows UTF-8 clipboard round-trip (`Bağlam → şıİöüç ğĞ`).
3. **Partial secret redaction & broader detection (`src/guards.ts`, `src/capture.ts`):**
   - Added patterns for `npm_`, `hf_`, `sbp_`, `gsk_`, `re_`, Telegram bot tokens, `Bearer` tokens, `.env`-style secret assignments, and full PEM private key blocks.
   - Automatic capture now uses `redactSecrets()` to replace only the secret span with `[redacted]` (preserving multi-line task plans) with a defense-in-depth `scanSecrets()` fallback to `HIDDEN`.
4. **Cross-platform `init` / `doctor` / `claude` hardening (`src/init.ts`, `src/doctor.ts`, `src/clients/claude.ts`, `src/cli.ts`, `src/project.ts`):**
   - `baglam init` now writes `.github/copilot-instructions.md` (VS Code) and `.windsurf/rules/baglam.md` (Windsurf), supports `--local` (idempotent `.git/info/exclude` without touching `.gitignore`) and `--name <name>`, and warns when no AI tools are registered via `baglam setup`.
   - `baglam doctor` checks every expected instruction file for installed tools (shared `expectedInstructionTargets()` helper) and flags stale absolute Node binary paths after nvm/fnm/Homebrew upgrades.
   - `claudeCode.install()` backs up `~/.claude.json` once before modifying it and updates when `Command:` Node path drifts.
5. **Data fidelity, brief priority, panel & site fixes:**
   - `exportJson` / `importJson` (`src/portable.ts`, `src/store.ts`) preserve handoff `request`, `requests`, auto-only `agentAt: null`, and per-project `autoCapture: false` (ignoring `BAGLAM_AUTO_CAPTURE=0` during export).
   - `formatHandoff` (`src/format.ts`) raised `Since then (git)` priority from `8` → `5` (above `Notes`, `Files`, `Done`).
   - Panel (`ui/`): added `history.imported` translations (`imported` / `içe aktardı`) + `historyLabel()` helper, auto-save hook health in Settings, and collapsible **Full request** + **Recent checkpoints** in `ContinueCard`.
   - Website (`site/`): removed unimplemented "replace" claim on the panel page, added Vercel security headers (CSP compatible with Astro's inlined module scripts/styles) and Twitter Card tags, removed unused `site/panel.jpg`.
   - Node 22 fix (`01cbd66`): removed transitive `node:sqlite` import from `jsdom` test `test/ui-app.test.tsx`.

### Landed After Live Audit (`d22a016`, `[Unreleased]` for `1.0.0`)
1. **Instant panel updates (`src/ui/api.ts`):** `GET /api/overview` now caches slow CLI tool probes (`claude mcp get`, ~1.5 s) for 30 s (`?fresh=1` bypasses cache) while always reading `pendingTotal` and `store.hookSeen()` live from SQLite. Eliminates the ~1.5 s sidebar badge lag observed during live browser testing.
2. **Parallel MCP handshakes in `baglam doctor` (`src/doctor.ts`):** Handshakes across detected tools now run concurrently via `Promise.all` while keeping deterministic output order. Real 6-tool Windows runtime dropped from **7.35 s → 3.17 s** (**2.3× faster**).
3. **`baglam handoff` CLI (`src/cli.ts`):** Now displays other branches with tasks in progress even when the current branch also has an active task (matching MCP and hook behavior).
