# Bağlam v1.0 · Milestone 5: Release candidate · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Bağlam releasable: portable data (export/import), proven speed, the deferred review items closed, a package that installs cleanly on Windows/macOS/Linux, bilingual docs and a landing page. Nothing is published.

**Architecture:** Export/import live in `src/portable.ts` over `ContextStore`; CLI gains `export`/`import`. Release plumbing is files only (`LICENSE`, `CHANGELOG.md`, `.github/workflows/ci.yml`, `scripts/pack-smoke.mjs`). Docs in `README.md` (EN), `README.tr.md`, `docs/`. Landing page is static `site/` (no build step).

**Spec:** `docs/superpowers/specs/2026-11-17-baglam-v1-design.md` §8 (export/import), §9 (quality and release).

## Global Constraints
- Nothing is published (npm, GitHub, Vercel) in this milestone.
- Version `1.0.0-rc.1`; licence MIT (spec: owner confirms before publishing).
- Performance budget: `context_brief` and `context_search` < 50 ms on 10,000 records (median of 20 runs, after warm-up).
- CI matrix: `windows-latest`, `macos-latest`, `ubuntu-latest` × Node `22.x`, `24.x`; steps: install, typecheck, test, build, pack smoke test.
- Export formats: `md` (readable `CONTEXT.md`: active records grouped by kind) and `json` (`{ format: "baglam/1", exportedAt, projects: [{ key, name }], entries: Entry[], events: [...] }`); import accepts only `json`, merges by entry id (existing ids skipped, never overwritten), and runs the secret scanner (blocked entries reported, not imported, unless `--force`).

## Review Focus
1. **Importing a file exported from another machine/version** (unknown fields, missing optional fields): imports what it understands; never crashes; reports skipped. → Task 1 test `import tolerates unknown and missing optional fields`.
2. **Importing the same file twice**: no duplicates. → Task 1 test `import is idempotent`.
3. **Markdown export of records with Markdown/HTML in them**: output stays readable and does not break the document structure (headings inside bodies are indented as quotes). → Task 1 test `md export quotes bodies`.
4. **Fresh install on a machine without `claude`, with spaces in the home path**: `npm pack` → install → `baglam --help` and `baglam doctor` run. → Task 4 `scripts/pack-smoke.mjs`.
5. **Slow DB under many agents** (busy): API answers 503 with a plain message rather than a raw SQLite string. → Task 3 test `busy database is a 503`.

### Task 3: Hardening (items deferred in M2–M4 reviews)
**Files:** `src/ui/server.ts`, `src/ui/http.ts`, `src/ui/api.ts`, `src/store.ts`, `src/clients/*.ts`, `src/host.ts`, `src/doctor.ts`, `src/cli.ts`. Tests in the matching test files.
- Panel: writes require `Origin` (same origin) or `Sec-Fetch-Site: same-origin`, and `content-type: application/json` when a body is sent → 403/415; HTML gets `Content-Security-Policy: default-src 'self'; connect-src 'self'; img-src 'self' data:; style-src 'self'; script-src 'self'; frame-ancestors 'none'`; SQLite busy/locked errors → 503 `{error: "database busy, try again"}`; 403 page wording no longer says "expired"; edit-and-approve in one transaction (`store.editAndApprove`); at most 20 open event streams per panel (oldest closed).
- Store/CLI: `trust add` warns when `--agent` is not a known setup id; docs note on flood limit for unverified clients.
- Config writes are atomic (write temp file in the same folder, then rename) for JSON, TOML and instruction files.
- `doctor` opens the DB read-only and does not create it when missing (reports "not created yet; it appears on first use").
- [ ] One RED→GREEN test per item; commit `fix: hardening from earlier reviews`.
