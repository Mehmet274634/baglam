## 2. Sistemin yetenekleri

| Yetenek | Ne işe yarar |
|---|---|
| **Ortak hafıza** | Ajanlar kararları, kuralları ve uyarıları Bağlam'a önerir. Sen onaylayınca bütün ajanlar görür. Onaylamadığın hiçbir şey diğer ajanlara gitmez. |
| **Ajanlar arası devir** | Bir ajan durunca (sen durdursan bile) iş kaybolmaz. Sonraki ajan "devam et" deyince kaldığı yeri bulur. |
| **Otomatik kaydetme** | Ajan kaydetmeyi unutsa bile isteğin, değişen dosyalar ve son durum kendiliğinden kaydedilir. |
| **Kaydetme hatırlatması** | Uzun süre ilerlemesini kaydetmeyen ajana hatırlatma gider. |
| **Otomatik mod** | İstersen ajanların önerileri anında paylaşılır, sen sonradan gözden geçirirsin. |
| **Güvenlik** | Şifre, API anahtarı gibi gizli bilgiler engellenir; her ajanın kimliği doğrulanır; her değişiklik kayıt altındadır. |
| **Panel** | Tarayıcıda Türkçe/İngilizce yönetim ekranı: onay kutusu, kayıtlar, projeler, ayarlar. |
| **Sağlık kontrolü** | `baglam doctor` her aracı kontrol eder, sorun varsa çözümünü söyler. |
| **Desteklenen araçlar** | Claude Code, Codex, Cursor, Antigravity, Gemini CLI, VS Code (Copilot), Windsurf |

## 3. Herhangi bir bilgisayara kurulum

**Gereken:** Node.js 22.13 veya daha yeni bir sürüm (nodejs.org'dan LTS sürümü).

```
npm i -g baglam
baglam setup
```

`baglam setup` bilgisayardaki bütün yapay zekâ araçlarını bulur ve Bağlam'a bağlar; değiştirdiği her dosyanın
yedeğini alır. Sonra Bağlam'ı kullanmak istediğin **her proje klasöründe** bir kez:

```
baglam init
```

Ardından:

1. Yapay zekâ araçlarını tamamen kapatıp yeniden aç.
2. Codex kullanıyorsan, Codex'te bir kez `/hooks` yazıp Bağlam'a güven.
3. Kontrol et: `baglam doctor` (hepsi ✓ ise kurulum tamam).

Mac için adım adım liste: [mac-test-checklist.tr.md](mac-test-checklist.tr.md).
